# 🌱 부모님 돌봄 첫걸음 — 천안 가족을 위한 AI 돌봄 길잡이

「AI 셰르파 양성과정」 프로젝트 기획서(전경숙)에 따라 만든 **모바일 웹 시제품**입니다.

## 4화면 흐름

| 화면 | 하는 일 |
|---|---|
| ① 우리 가족 상황 | 지역(천안시 전체/동남구/서북구), 대상, 필요한 도움을 큰 버튼으로 고르고 자유 문장 입력. 일상어 → 제도 용어 추천 |
| ② 더 확인할 내용 | 입력에서 빠진 핵심 조건만 2~3개 질문 (지내는 곳·시간대·장기요양등급·이동·문의한 곳). 건너뛰기 가능 |
| ③ 천안 지역 자원 | 공공데이터에서 천안시 행만 골라 서비스 유형별 목록. 쉬운 설명, 전화 걸기, 출처·기준일 표시 |
| ④ 문의 메모 | 상황 요약 + 기관별 질문 3개 + 다음 할 일. 복사·저장(.txt)·인쇄 |

## 안전 원칙 (기획서 그대로)

- 기관명·주소·연락처는 **CSV 값 그대로**만 표시합니다. AI에는 기관 이름·연락처를 보내지 않고 서비스 종류만 보냅니다.
- 자료가 없으면 결과를 만들어 내지 않습니다.
- 자격·비용·의료 상태를 단정하지 않고 "기관 확인 필요"로 안내합니다.
- 로그인 없음, 입력 내용 서버 저장 없음. 실명·주민번호·진단명 입력 자제 안내.

## 실행

```bash
npm install
npm run care          # http://localhost:3100
```

- `.env` 에 `ANTHROPIC_API_KEY` 가 있으면 **AI 모드**(Claude가 상황 정리·확인 질문·문의 메모 문장 작성), 없으면 **간편 모드**(규칙 기반)로 동작합니다.
- AI 모델은 `CARE_MODEL` 로 바꿀 수 있습니다 (기본 `claude-opus-5-5`).
- 설치 없이 보기: GitHub Pages `…/super-duper-happiness/care/` (간편 모드).

## 데이터 넣기

1. [공공데이터포털 15173720](https://www.data.go.kr/data/15173720/fileData.do)에서 국민건강보험공단 「통합돌봄 서비스 자원」 CSV를 내려받습니다.
2. 둘 중 하나:
   - 앱의 **[자료] → CSV 파일 선택** (그 브라우저에만 저장)
   - 운영자가 `care/public/data/resources.csv` 로 넣기 (+ `resources.json` 에 기준일) → 모든 사용자에게 적용
3. 아무 자료도 없으면 **시연용 가상 자료**(실제 기관 아님, 전화 걸기 꺼짐)로 화면을 보여 줍니다.

EUC-KR/UTF-8 CSV 모두 읽고, 열 이름(시군구·제공기관명·연락처·주소·서비스 분류·프로그램명)을 자동으로 찾습니다.
