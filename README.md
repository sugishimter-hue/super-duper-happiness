# 🏢 나의 AI 사무실 (3단계)

1인 창업자가 **대표(CEO)** 역할만 하고, 실제 업무는 **AI 직원들**이 나눠서 처리하는 웹앱입니다.
전경숙 대표님(재무솔루션연구소 · AI글로벌유니패스아카데미)의 업무에 맞춰 직원 11명이 미리 채용되어 있습니다.

## 어떻게 일하나요?

```
대표: "이번 달 은퇴설계 세미나 열자"
   ↓  💬 업무 지시
🤵 비서실장 유니가 업무를 쪼개서 알맞은 직원에게 배정
   ↓
🎓 강의기획자 · 📢 SNS마케터 · 🤝 고객관리매니저 … 가 동시에 작업
   ↓
✅ 결재함에 결과물 도착 → 대표가 [승인] / [수정 요청] / [반려]
```

- 외부로 나가는 것(고객 문자, SNS 게시 등)은 **앱이 직접 보내지 않습니다.** 승인한 결과물을 복사하거나 저장해서 쓰시면 됩니다.
- 금융·보험 관련 결과물은 **분석 초안**까지만 만들고, 상품 권유나 수익 보장 표현은 쓰지 않도록 규칙이 들어 있습니다.

## 주요 화면

| 화면 | 기능 |
|---|---|
| 🏠 대시보드 | 업무 지시창, 비서실장 아침 브리핑, 업무 현황, 칸반 보드 (작업 중 → 결재 대기 → 완료) |
| ✅ 결재함 | 결과물 확인, 승인, 수정 요청(피드백 반영해 다시 작성), 반려, 복사, `.md` 저장 |
| 👥 직원 관리 | 조직도, 직원에게 직접 지시, 직원 채용·편집·퇴사, 직원별 **업무 지침서** 수정 |
| 📚 지식창고 | 강의 소개, 서비스 정보, 말투 원칙 등을 저장하면 모든 직원이 참고 |
| 📈 주간 보고 | 주별 지시·완료·절약 시간, 요일별 그래프, 직원별 실적, 비서실장 총평, `.md` 저장 |
| ⚙️ 설정 | Google·카카오톡 연결, 알림 켜기/끄기, 아침 자동 브리핑 시간, PPT 기본 색상, 비밀번호 변경, 로그아웃 |

### 3단계에서 추가된 기능

- 💬 **카카오톡 알림**: 대표님 카카오톡 **나와의 채팅**으로 알림을 보냅니다. 고객에게는 보내지 않습니다.
  - 결과물이 결재함에 도착하면 보냅니다. 1분 안에 여러 건이 오면 한 번에 모아 보냅니다.
  - 아침 자동 브리핑을 보냅니다.
  - 월요일 아침에 지난주 업무 보고를 보냅니다.
- 📊 **강의 PPT 자동 생성**: 결과물을 강의용 16:9 슬라이드로 구성하고, 발표자 노트까지 넣어 **PowerPoint 파일(.pptx)**로 만듭니다.
- 🖼️ **카드뉴스 자동 생성**: 결과물을 인스타그램용 정사각형 카드 5~8장과 캡션·해시태그로 만듭니다. 카드는 **PNG 이미지**로 한 장씩 받거나 **PowerPoint 파일**로 받아 고칠 수 있습니다.
  - 라벤더, 네이비 골드, 코랄, 포레스트 4가지 색상 중에서 고를 수 있습니다.
- 📈 **주간 업무 보고서**: 한 주 동안 AI 직원들이 한 일과 **절약한 시간(추정)**을 정리합니다.
  - 절약 시간은 업무 1건당 기본 40분으로 계산하며, 설정에서 바꿀 수 있습니다.

### 2단계에서 추가된 기능

- 🔐 **로그인**: 처음 켜면 비밀번호를 정하고, 그다음부터는 비밀번호를 넣어야 들어올 수 있습니다. 5번 틀리면 15분 동안 잠깁니다.
- 📅 **Google 캘린더**: 대시보드에 오늘·내일 일정이 나옵니다. 캘린더는 **읽기만** 합니다.
- 📧 **Gmail**: 승인한 결과물을 **임시보관함에만** 저장합니다. 자동으로 보내지 않으니 Gmail에서 확인하고 직접 보내세요.
- 📁 **Google Drive**: 승인한 결과물을 Drive의 **"AI 사무실" 폴더**에 Google 문서로 저장합니다. 앱이 만든 파일 외에는 볼 수 없습니다.
- ☀️ **아침 자동 브리핑**: 매일 정한 시간(기본 08:00)에 비서실장이 **캘린더 일정과 업무 현황**을 보고 브리핑을 써 둡니다. 그 시간에 앱이 꺼져 있었다면 다음에 켤 때 바로 만듭니다.

## 체험판 (설치 없이 화면 미리 보기)

`demo/` 폴더의 스크립트로 서버 없이 브라우저에서 바로 열리는 체험판 HTML을 만들 수 있습니다. 예시 업무와 예시 일정이 들어 있고, AI·Google·저장은 실제로 동작하지 않습니다.

```bash
node demo/build.mjs
```

## 실행 방법

필요한 것: [Node.js](https://nodejs.org) 20.12 이상

```bash
npm install
```

**① 체험(데모 모드):** API 키 없이 화면과 흐름을 확인할 수 있습니다. 결과물은 예시 문구로 나옵니다.

```bash
npm run demo
```

**② 실제 사용:** [Claude 콘솔](https://console.anthropic.com)에서 API 키를 발급받아 `.env` 파일에 넣습니다.

```bash
cp .env.example .env
```

`.env` 파일을 열어 `ANTHROPIC_API_KEY=` 뒤에 키를 붙여 넣고 실행합니다.

```bash
npm start
```

그다음 브라우저에서 http://localhost:3000 을 엽니다. 처음에는 **비밀번호를 정하는 화면**이 나옵니다.

> 💡 검은 창(명령 프롬프트)을 닫으면 앱도 꺼집니다. 쓰는 동안에는 최소화만 해 두세요.

비밀번호를 잊었다면 앱을 끈 뒤 아래 명령을 실행하고, 다시 켜서 새 비밀번호를 정하세요.

```bash
npm run reset-password
```

## Google 연동 준비 (선택, 처음 한 번 약 10분)

Google 캘린더·Gmail·Drive를 쓰려면 대표님 전용 "Google 연결 열쇠"를 한 번 만들어야 합니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에 대표님 Google 계정으로 로그인 → 위쪽에서 **새 프로젝트** 만들기 (이름 예: `AI 사무실`)
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**에서 세 가지를 검색해 각각 **사용**을 누릅니다.
   - Google Calendar API
   - Gmail API
   - Google Drive API
3. **API 및 서비스 → OAuth 동의 화면**
   - 사용자 유형: **외부** → 앱 이름 `AI 사무실`, 이메일은 대표님 Gmail
   - **테스트 사용자**에 대표님 Gmail 주소 추가
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 리디렉션 URI**: `http://localhost:3000/auth/google/callback`
5. 만들어진 **클라이언트 ID**와 **클라이언트 보안 비밀번호**를 `.env` 파일의 `GOOGLE_CLIENT_ID=`, `GOOGLE_CLIENT_SECRET=` 뒤에 붙여 넣고 앱을 다시 켭니다.
6. 앱의 **⚙️ 설정 → Google 계정 연결하기**를 누르고 권한을 허용합니다.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → AI 사무실(으)로 이동**을 누르세요. 대표님이 직접 만든 앱이라 나오는 안내입니다.

> ⚠️ OAuth 동의 화면이 **테스트** 상태이면 Google 정책상 **7일마다 연결이 풀립니다.** 그럴 때는 설정에서 다시 연결하면 됩니다. 번거로우시면 OAuth 동의 화면에서 **앱 게시(프로덕션)**를 누르세요. 대표님 혼자 쓰는 것은 문제없습니다.

앱이 Google에 요청하는 권한은 다음 세 가지뿐입니다.

| 권한 | 하는 일 | 하지 않는 일 |
|---|---|---|
| 캘린더 읽기 | 오늘·내일 일정 보기 | 일정 수정·삭제 |
| Gmail 작성 | 임시보관함에 초안 저장 | 메일 읽기, 자동 발송 |
| Drive (앱 파일) | "AI 사무실" 폴더에 문서 저장 | 대표님의 다른 파일 보기 |

## 카카오톡 알림 준비 (선택, 처음 한 번 약 10분)

1. [카카오 개발자 사이트](https://developers.kakao.com/)에 카카오 계정으로 로그인 → **내 애플리케이션 → 애플리케이션 추가하기** (앱 이름 예: `AI 사무실`)
2. 만든 앱에서 **플랫폼 → Web 플랫폼 등록**, 사이트 도메인에 `http://localhost:3000` 입력
3. **카카오 로그인** 메뉴에서 **활성화 설정: ON**, **Redirect URI**에 `http://localhost:3000/auth/kakao/callback` 등록
4. **카카오 로그인 → 동의항목**에서 **카카오톡 메시지 전송**을 **선택 동의**로 설정
5. **앱 키**의 **REST API 키**를 복사해 `.env`의 `KAKAO_REST_API_KEY=` 뒤에 붙여 넣고 앱을 다시 켭니다.
   - 보안 메뉴에서 Client Secret을 "사용"으로 켰다면 그 값도 `KAKAO_CLIENT_SECRET=`에 넣습니다.
6. 앱의 **⚙️ 설정 → 카카오톡 연결하기** → 동의 → **테스트 메시지 보내기**로 확인합니다.

> 💡 알림 속 [사무실 열기] 버튼은 앱이 켜진 **그 컴퓨터에서만** 열립니다. 휴대폰에서 바로 열려면 앱을 인터넷에 배포해야 합니다. 그때는 위 주소들을 `https://내주소`로 바꿔 등록하세요.

## 데이터와 보안

- 업무·직원·지식창고·설정은 `data/db.json`에 저장됩니다. Git에는 올라가지 않습니다.
- 비밀번호는 원래 글자가 아니라 **암호화된 형태(scrypt 해시)**로만 저장됩니다.
- Google 연결 정보(갱신 토큰)도 `data/db.json`에 들어 있으니 이 파일은 다른 사람과 공유하지 마세요.
- API 키는 서버(`.env`)에만 있고 브라우저로는 전달되지 않습니다.
- 고객 주민번호, 계좌번호 같은 민감정보는 지시문이나 지식창고에 넣지 마세요.
- 인터넷에 공개 배포할 때는 반드시 **https 주소**로 배포하고, `.env`의 `APP_URL`을 그 주소로, Google 리디렉션 URI도 `https://내주소/auth/google/callback`으로 바꾸세요.

